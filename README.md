# PRIMAL FRONTIER — Unity 6 Web Demo Source

This is a REAL Unity project source, not an HTML game.

## What is playable now
- Third-person survivor movement + camera
- Mobile on-screen movement/action buttons
- Survival HUD: HP, stamina, hunger, thirst
- Prehistoric island test environment generated at runtime
- Small roaming raptor-like creatures
- Distant large sauropod
- Basic hunting interaction and loot feedback
- Gathering feedback
- Campfire light, fog, jungle test environment
- Thai quest HUD

IMPORTANT: the realistic screenshot/concept is the visual target. This starter build uses Unity primitives/placeholders because photorealistic human/dinosaur models, animations, PBR vegetation, water, terrain and VFX are external 3D art assets and are not bundled here.

## Open it
1. Install Unity Hub on Windows or Mac.
2. Install Unity 6 (6000.0 LTS recommended) with Web Build Support.
3. Extract this ZIP.
4. Unity Hub > Add > Add project from disk > select `PrimalFrontierUnity`.
5. Let Unity import packages.
6. Open `Assets/PrimalFrontier/Scenes/PrimalFrontier_Demo.unity`.
7. Press Play.

## Build for Unity Play
1. In Unity choose `PRIMAL FRONTIER > Build Web Demo`.
2. Wait for Web build to finish.
3. Output is created in `Build/Web`.
4. Upload/publish the Web build through Unity Play / Unity's Web publishing workflow.
